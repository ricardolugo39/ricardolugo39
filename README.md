## Featured work

### Branch Sales Command Center

An interactive dashboard for an industrial distributor’s sales manager. It brings year-to-date branch performance, declining customer accounts, and overdue opportunity follow-ups into one view. The public demo uses fictional data.

**[Open the live demo](https://ricardolugo39.github.io/branch-sales-demo/)** · [View the demo source](https://github.com/ricardolugo39/branch-sales-demo)

### Resume Agent

A tool for preparing tailored résumés and cover letters, tracking applications, and keeping a history of résumé versions. I built it with Python, Streamlit, SQLite, and the OpenAI API.

## How I work with AI tools

For the dashboard, I defined the manager’s decisions and chose what the homepage should prioritize. I used Claude Design to explore layouts and refine the clickable prototype, then used Codex to implement the chosen direction in the internal app. I compared the working UI with the prototype on desktop and mobile, directed revisions, and reviewed the result before approving release.
